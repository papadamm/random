# warp-13-vintage-protocol

The Microchip PICSTART Plus (Copyright (C) 2004 Microchip Technology Inc.) is a device to program Microchip PIC MCUs. Mine is a beige box with a ZIF socket, and has an upside-down RS-232 port and a barrel jack for a 9V power supply.

Historically the software MPLAB IDE was provided by Microchip. Over time open source community members developed an alternative piece of software, a CLI utility with the name picp licensed under the GPL.

The file uploaded supposedly contains protocol information for the RS-232 interface used between the host computer and the PICSTART Plus. For more details see file picp_0.6.8.orig.tar.gz with date 2009-05-09.

The original picp software was developed between 1999 and 2005, and it was once available at:
http://home.pacbell.net/theposts/picmicro

Anyone interested in this may want to check out the information from the Debian tracker:
https://tracker.debian.org/news/272155/accepted-picp-067-1-source-i386/
